# Devtree Portfolio Website

This is a company portfolio website built using React.js. The website provides an overview of the company, showcases services, and allows users to upload resumes securely to apply for job opportunities. The uploaded resumes are securely stored in Firebase, ensuring data protection. The website is fully responsive and hosted on Vercel.

## 🚀 Features

- **Built with React.js**
- **Resume Upload Feature** for job applicants
- **Secure Storage in Firebase**
- **Responsive Design for all devices**
